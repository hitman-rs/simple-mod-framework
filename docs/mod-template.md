# Mod template

A [GitHub template](https://github.com/hitman-rs/smf-mod) is provided for ease of use in distributing mods. Providing the URL of a repository created from this template as your mod's `url` gives you automatic versioning, changelogs and one-click updates for users. Additionally, the template comes with CI validation which applies the same logic as SMF's mod validation, giving you quick feedback on commits and pull requests.
