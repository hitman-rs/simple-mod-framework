# RPKG mods

An RPKG mod is a mod distributed as a set of patch RPKG files which a user is expected to copy into the Runtime folder.

These mods have substantially worse compatibility with other mods, and with game updates. They can also cause issues with the framework, which generally expects a clean, untouched set of game files to work from. As such, you should always distribute mods you make as SMF mods, which also gives a variety of useful extra features like update checking.

Since RPKG mods were common in the early days of H3 and 007 First Light modding, SMF does have rudimentary support for users to import existing RPKG mods. These are automatically extracted and migrated as much as possible to SMF formats. However, as these mods become outdated, SMF's ability to produce a high-quality result is degraded. In general, an issue in an imported RPKG mod is not considered a bug with SMF.
