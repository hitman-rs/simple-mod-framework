# Language files

Language files in the format of [HMLanguages](https://tonytools.win/tools/hmlanguagetools), as extracted by GlacierKit.

For mod localisation, you should use the `localisation` key in the manifest; the `locr.json` file type is designed for instances where it is necessary to completely override a localisation file or introduce a new localisation file.
