# Mod IDs

The format of mod IDs has always been capitalised reverse URI style - `AuthorName.ModName`. SMFv2 accepted a slightly wider range of formats than this; in SMFv3, this style is now strictly enforced for consistency. If your mod ID followed any of the following formats, **you should change it** in the next mod update to the correct format:

| Original mod ID  | Automatically upgraded ID | Correct ID       |
| ---------------- | ------------------------- | ---------------- |
| `me.epicmod`     | `me.Epicmod`              | `Me.EpicMod`     |
| `Author.woa-mod` | `Author.WoaMod`           | `Author.WOAMod`  |
| `mod.name`       | `mod.Name`                | `Author.ModName` |
