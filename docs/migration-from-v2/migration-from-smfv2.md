# Migration from SMFv2

SMFv3 introduced a number of breaking changes, some of which require manual changes to adapt to.

The process for adding a mod via the _Add a Mod_ button automatically migrates older mods as best it can. In general, most SMFv2 mods will work fine on SMFv3 with no manual changes. However, some cleanup is required internally if you intend to work any further on the mod. Consult the other pages in this section for explanations of these changes.

The specific areas of focus for **manual** changes are:

* [mod-ids.md](mod-ids.md "mention")
* [option-ids.md](option-ids.md "mention")
